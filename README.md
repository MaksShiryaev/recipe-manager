1)Recipe Manager
Система для управления рецептами, масштабирования порций и создания списков покупок.
2)Описание
Консольное приложение позволяет создавать блюда, добавлять ингредиенты, масштабировать количество порций и автоматически суммировать продукты из разных рецептов для похода в магазин. Поддерживаются диетические рецепты с категориями (веган, без глютена, кето).
3)Требования
- Python 3.8 или выше
- Git
